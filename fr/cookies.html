Cette information concerne le site internet

Cette page concerne le site web Pastilo L'archive de l'application et les autorisations sont décrites séparément dans la politique de confidentialité.

Pas de cookies ou de suivi

Le code du site ne définit aucun cookie et n'utilise aucun pixel de suivi, aucune empreinte digitale ou analyse. Les polices, images et scripts sont locaux. En rejetant l'avis, vous enregistrez pastilo.cookieNotice.dismissed.v1 = 1 dans sessionStorage pour la session d'onglet. Cette valeur n'identifie pas les visiteurs et n'est pas envoyée à un serveur.

Vos choix de voyage

La valeur dure pendant la session de l’onglet, y compris les restaurations de session du navigateur. Si sessionStorage est bloqué, l’exclusion fonctionne sur la page en cours. Pastilo utilise localStorage pour mémoriser la langue sélectionnée sur cet appareil sur le site Web et Coach. Coach peut également mémoriser le dernier dossier de travail via IndexedDB. Vous pouvez effacer ces préférences dans les paramètres de votre navigateur. Sans JavaScript, le contenu et les liens restent lisibles.

Hébergement, cache et liens

GitHub Pages reçoit des données techniques de connexion pour fournir et protéger le service. Aucun cookie ne signifie pas aucun traitement de données personnelles. Votre navigateur peut mettre en cache des ressources. Les liens externes ouvrent des services distincts avec leurs propres politiques; ceux-ci ne sont pas intégrés dans ce site.
